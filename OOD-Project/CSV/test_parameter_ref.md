# รายละเอียดการทดสอบ

การทดสอบแต่ละรายการ สามารถอ่านรายละเอียดวิธีการทดลอง ตัวแปรต้น ตัวแปรควบคุม และ salt ที่ใช้ได้จากในเอกสารรายงาน

1. CSV\test_functions_csv\

- การทดสอบฟังก์ชันแบ่งออกเป็นสองส่วน ได้แก้

1.1 การทดสอบความถูกต้องของฟังก์ชัน: รายงานหน้าที่ 32-48

1.2 การทดสอบกรณีขอบ: รายงานหน้าที่ 49

2. CSV\test_A\

- การทดสอบการเพิ่มผู้เข้าพักด้วยชุดทดสอบ A: รายงานหน้าที่ 50-51

3. CSV\CSV_TestB\

- การทดสอบเปรียบเทียบประสิทธิภาพการจัดการอาคารด้วยชุดทดสอบ B: 52-53

4. CSV\test_C_results.csv

- การทดสอบการกระจายตัวของผู้เข้าพักด้วยชุดทดสอบ C: รายงานหน้าที่ 54

5. CSV\app_output\

- ผลลัพท์จาก \app.py
