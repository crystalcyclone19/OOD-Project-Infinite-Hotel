## รายการทดสอบขั้นตํ่า

1.  เพิ่มแขกใหม่ทั้งช่องทางเดิมและช่องทางใหม่ แล้วตรวจว่าที่อยู่ห้องของแขกเดิมไม่เปลี่ยนแม้แต่คนเดียว
2.  ตรวจเลขห้องตามตัวอย่างสูตร และตรวจว่ารหัสแขกที่ต่างกันไม่ทําให้ที่อยู่ห้องซํ้ากัน
3.  ปฏิเสธรหัสแขกซํ้า รวมกรณีเพิ่มเป็นกลุ่มที่ซํ้าเพียงบางรายการ โดยข้อมูลเดิมต้องไม่เปลี่ยน
4.  ค้นหาที่ตําแหน่งตรงจุดอาคารพอดี ระหว่างจุด และหลังจุดสุดท้าย (กรณีวนกลับต้นวงแหวน) รวมถึงกรณี virtual node ชนกันด้วยข้อมูลจําลอง
5.  เพิ่มและลบอาคารเมื่อ V > 1 แล้วตรวจว่าผู้ย้ายเป็นไปตามกติกา จํานวนแขกรวมไม่หายไม่เพิ่ม และจํานวนรายการย้ายตรงกับยอดที่รายงาน
6.  กรณีขอบตามหัวข้อ 4.5 ทั้งหมด และตรวจว่าจํานวนแถวในไฟล์ CSV ตรงกับจํานวนแขกปัจจุบัน ต้องส่งสคริปต์ทดสอบอัตโนมัติสําหรับกติกาหลัก ใช้ assert หรือ unittest ได้ พร้อมรายงานผลผ่าน/ไม่ผ่านและคําอธิบายกรณีที่ยังไม่ผ่าน ภาพหน้าจออย่างเดียวไม่นับเป็นหลักฐานความถูกต้อง

## โครงสร้างการทดสอบ

1. ระบุส่วน/ข้อที่จะทดสอบ
2. ทดสอบและแสดงตัวอย่างผลการทดสอบออกทางหน้าจอ
3. สรุปผล จำนวนชุดทดสอบที่ผ่าน/ไม่ผ่าน และรายการชุดทดสอบที่ไม่ผ่าน ทั้งทาง terminal และสร้างไฟล์ csv สำหรับรายงานผลการทดสอบทั้งหมด

## การจัดเก็บไฟล์ CSV

จัดเก็บทั้งหมดไว้ที่ CSV\test_functions_csv โดยแยกรายการตามโฟลเดอร์หลักทั้งหมด
